## Learnings
- 252-LOC bash helper folds into ~250 LOC TS with 10 named exports (findRepoRoot, getSpecsDirs, resolveSpecsDirs alias, getDefaultDir, findSpec, resolveCurrent, listSpecs + ResolverOptions/FindSpecResult/SpecEntry types).
- Serialized paths (return values used by state files / context blocks) use `path.posix.join`; on-disk fs probes use `path.join` per design.md "Cross-Platform Path Handling" table.
- v6 bash relied on `cwd === repo root`; added explicit `findRepoRoot()` walker (looks for `.git` or `.claude/curdx-flow.local.md`) so hooks invoked from sub-dirs still resolve.
- Exit-code semantics from bash (`0/1/2`) ported as discriminated union `FindSpecResult` so callers can distinguish not-found vs ambiguous without losing match list.
- `.current-spec` content stripped with `\s+` regex to match `tr -d '[:space:]'`.
