## Learnings
- Node 20 lacks `fs.globSync` and `fs/promises.glob`; rolled own glob → RegExp
  converter (`**` → `.*`, `*` → `[^/]*`, `?` → `[^/]`, escape regex specials)
  + `readdirSync` recursive walker. Zero new deps.
- Best-effort cleanup pattern: ENOENT silently skipped, other unlink errors
  go to stderr but loop continues. Caller never aborts mid-cleanup.
- Safety guard rejects absolute paths and `..` segments before walking, so a
  stray `/etc/passwd` pattern can't escape CWD.
- Smoke-tested both dry-run (lists matches, file untouched) and live run
  (file unlinked); confirmed idempotency on second invocation (`0 file(s) removed`).
