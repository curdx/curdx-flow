## Learnings
- `$unset` operator added at root level only; non-recursive per design §2.
- `stripUnset` uses object destructuring `{ $unset: _drop, ...rest }` to drop reserved key before `deepMerge`, so existing patches without `$unset` are fully transparent (verified: `{"y":2}` patched into `{"x":1}` yields `{"x":1,"y":2}`).
- `applyUnset` runs AFTER `deepMerge` so combined patch `{"completed":false,"$unset":["completedAt"]}` first writes `completed=false` then deletes `completedAt` key (verified: `{"completed":true,"completedAt":"X","other":"keep"}` → `{"completed":false,"other":"keep"}`).
- Invalid shape (e.g. `{"$unset":"notarray"}`) exits 1 with stderr `merge-state: $unset must be string[]` — matches design §2 contract.
- Missing keys in `$unset` array silently no-op (`delete` on absent key is a JS no-op) — matches case U-3.
- Smoke tested with `npx tsx` directly on src; full unit test coverage will land in sibling task 1.4.
